# Box Audit

Company site for Box Audit. The line is “Think inside the box”: the money is already in the books, and clients pay only out of what is recovered.

## Preview

From this folder:

```bash
python3 -m http.server 8765
```

Open http://127.0.0.1:8765/

## Contact

Scan requests open an email to `jay.cs.iit@gmail.com`. Change `CONTACT_EMAIL` in `js/main.js` and the same address in `index.html` if that inbox should move.

## What stays off this site

The internal company plan is not part of the site. It includes fundraising, formation, and rate questions that do not belong on the public page.
